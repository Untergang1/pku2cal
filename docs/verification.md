# 当前验证边界

课表通过显式命令导入 YAML；本地生成、Pages 发布和 Worker 部署共用离线日历生成逻辑。使用方法见 [README](../README.md)，模块与数据契约见[系统设计](design.md)。

## 自动验证覆盖

- YAML 安全解析、中文与前导零、注释、多个时段、不连续教学周、单双周、pending/ignored、重复事件和空课表。
- 上游结构与学期检查、上海日期边界及导入期间跨越截止时间；离线生成不受导入窗口限制。
- 私密文件原子替换、权限、失败清理、课表备份、拒绝隐式覆盖、并发锁和拉取期间编辑。
- 校历公开请求与重定向限制、校本部春秋学期区分、跨年日期、停补课与待公布提醒；配置备份、保留作息和命名空间、拒绝损坏配置、预览不落盘，以及导入后两种发布入口使用相同 ICS。
- 作息表选择及乱序节次、停补课、ICS 独立解析和稳定 UID；本地文件、Pages staging 与 Worker 响应的一致性。
- Pages 快照大小与摘要校验、语义比较及发布编排；Worker 快照响应、当前部署识别、令牌复用与轮换失败重试。平台编排使用合成响应。
- 构建前清理孤立编译模块，同时保留有效输出、独立 bundle 和非编译文件。
- macOS/Linux CI 使用相同安装、类型检查、构建、测试和两种合成输入的 Wrangler dry-run 命令。

## 实测边界

既有 Node 真实账号联调已确认认证和主修课表页面可获取；上游版本、页面差异及作息表依据见[参考资料](reference.md)。本次清理前的只读配置核对确认：Pages 默认分支已使用手动快照工作流且旧 Secrets 已清除；Worker 使用 `snapshot-v1`，没有 KV 绑定或旧 PKU Secrets。配置核对不等于线上日历内容验收。

本地 Linux 已通过类型检查、构建、134 项相关测试、两种合成输入的 Wrangler dry-run，以及当前私密 YAML 的只读检查。文档相对链接检查通过；保留的课表、当前 ICS、Worker bundle、部署配置和令牌状态已核对字节一致。
