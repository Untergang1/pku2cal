# 当前验证边界

本版本将课表获取改为手动 YAML 导入，生成与两种发布方式均使用离线快照。历史自动刷新实现的验证结果不能作为新实现的云端验收，旧记录保存在[验证变更日志](changelog.md)。

## 自动验证覆盖

- YAML 1.2、中文和前导零、注释、多个时段、不连续教学周及单双周、pending/ignored、非法字段、重复事件和空课表。
- 上游学期检查、人工绑定的上海日期边界、旧确认与补丁向 YAML 的迁移，以及迁移前后的 ICS 内容和 UID 一致性。
- 本地文件原子写入、0600 权限、备份、拒绝隐式覆盖、并发锁、拉取期间编辑、获取或备份失败保留旧文件。
- 相同快照在本地文件、Pages staging 与 Worker 响应中的一致性；无凭据、无网络下生成，以及学期结束后继续生成。
- Pages 单 Secret 编码、解压大小限制、摘要错配、语义比较、首次/变化/强制发布及不变跳过；发布编排使用模拟 GitHub 响应。
- Worker 生产入口在本地 workerd 中提供内嵌快照，不依赖 PKU Secrets 或 KV；部署编排、状态迁移、令牌复用和清理失败使用模拟 Cloudflare 响应。
- CI 继续在 macOS/Linux 使用相同安装、类型检查、构建、测试和合成输入的 Wrangler dry-run 命令。
